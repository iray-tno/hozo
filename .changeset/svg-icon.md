Add `Icon`, which draws an icon from the `IconNode` data `lucide` exports: an inline `<svg>` on the Web and `react-native-svg` on Native. No icon set is bundled; the application imports the icons it uses. An icon is decoration (hidden from assistive technology) unless it has an `accessibilityLabel`, in which case it is one image with that name.
