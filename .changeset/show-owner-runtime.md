`hozo show` says when a class list it cannot read is still resolved by its pattern owner with the owner's state, as a Chip's `className={cls}` or a Menu's `itemClassName={cls}` is on Native: a runtime `hover:` works there, unlike on a View. The JSON gives the owner as `owner`. A runtime slot list is also reported under the prop it was written as, not as `className`.
