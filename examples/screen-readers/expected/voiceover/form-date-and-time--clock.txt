# re-measured what run 36294264902 approved. The fact that file recorded is
# unchanged: the value read out is the whole time, not the field's own digits.
# "stepper" rather than "spin button" is VoiceOver's name for the role, and
# the period stays a button -- which is the design: a spinbutton carries
# `aria-valuenow`, and a number for "am" is a number nobody can read.

# are named rather than hidden: a reader who reaches one should hear which
# field it steps. This reader keeps the group's name on a line of its own,
# so unlike NVDA's file nothing here had to change to accommodate them.

# reads identically under its own name. Both are approved, because "these two
# layouts are one markup" is the claim the story exists to make.
