# Native pattern gap precedence during interaction

This extends [the status-bearing owner slice](status-pattern-gap-composition.md)
with changing-state evidence. It changes no production code, ordering policy,
generated ABI, eligibility or public API.

## What runs

The existing source-backed matrix now also drives eight real interaction
owners: Chip removal, Listbox option, Menu trigger/item, Combobox option,
Tabs tab, Pagination current item and a clickable Stepper step. Each runs
uncompiled, literal, opaque and spread caller routes, three author inputs,
seven frames and eight Yoga layouts: **5,376 observations, zero mismatches**.
The retained rest-state matrix has3,360observations, also zero mismatches.

Frames call the actual Native host handlers for hover-in, press-in, press-out,
hover-out, focus and blur, reselecting the committed owner each time. Without
an authored gap, class axes change from8/2 to8/4,12/4,8/4,8/2,6/2 and8/2.
Those changing-value controls prevent a permanently pinned author style from
hiding broken event/fact wiring. Frozen generic-gap and nested axis inputs
retain16/16 and6/24 respectively across the same events. Exact owner counts
and scanned candidate-presence checks remain.

Combobox's DOM focus belongs to its input, not an option. Its option fixture
therefore uses hover/press classes only and does not claim focus support;
Native option focus leaves the8/2 control unchanged. Stepper's generated
fixture explicitly authors `onStepPress`, as the compiler's interactive
contract requires. Negative controls retain both the Combobox focus refusal
and the Stepper refusal when a spread hides that declaration. The initial
overbroad fixture hit these diagnostics; the owner model was corrected, not
the diagnostics suppressed or the production capability widened.

## Validation and limits

The focused file passed **four tests**, no skips, in13.83s. This includes
the rest matrix, inactive Stepper getters, changing-state matrix and explicit
refusal controls. The final combined file/dynamic-slot/inheritance/raw-source
cache run passed **74 tests**, no skips (27.78s). Work used CPU1/Idle/serial,
no subagents. Logs are retained
under ignored `artifacts/tailwind-order/namespace-invariance/pattern-state-gap-*`.

The host is still a React Native stand-in. Yoga3.2.1WASM measures effective
gaps in a fixed layout, not full widget/device pixels. Calling handlers does
not establish OS pointer/touch/focus delivery, AT behavior or browser parity.
There is no new rendering subscription or measured render-speed claim.
No full local root suite, app/Metro/device build, report or headline coverage
change is claimed. No Rust changed or addon rebuild was needed.

Other owners, state-gate changes such as page/status replacement, direct
authored style functions, clearing/null, percentages, mixed StyleX tiers and
contextual grid remain separate. This evidence does not remove gap's
canonical assessment barrier. No changeset per user instruction.
