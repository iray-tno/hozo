## How to read this audit

This is a reproducible history ledger, not 254 claims of new public APIs. Grouping is a first-pass routing aid based on scope and a few explicit cross-cutting PRs. Feature/fix/performance/refactor entries are candidates for the capability notes; test/docs/CI/build/chore entries supply supporting evidence or maintenance. Intermediate implementations and later repairs are summarized once in the [release changelog](../../CHANGELOG.md).

Final-source cross-checks: public export maps in `scripts/package-metadata.mjs`; entry points in `packages/{three,form,ui,native,patterns,primitives,behaviors,svg}/src`; compiler source discovery and lowering; peer-range diffs; motion ADR 007; native-module ADR 006; Three capability/scene reports; SVG filter reference; packed-consumer and release verification. The existing core/engine/rn-compat/svg package split predates v0.1.0 and is not a new 0.2.0 feature. React 19 and the RN >=0.86 peer floor also predate this release.

The complete changed-path inventory and this one-off generator are retained locally under `artifacts/release-0.2.0-audit.json` and `artifacts/release-0.2.0-audit.mjs`. The committed ledger can independently be reconstructed with `git log --first-parent --reverse --format="%H %s" v0.1.0..4aa0ca0224d43715ec017dc59c1ac3bb4ac9429f` and each commit's first-parent diff.
