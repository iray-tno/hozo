A `Skeleton` is a raised surface that pulses where content will be. It is
hidden from assistive technology, since a reader has nothing to gain from
"blank, blank, blank", and it stops pulsing under reduced motion.

<UiExample source={source} file="SkeletonDemo.tsx">
  <SkeletonDemo client:visible />
</UiExample>

- **`className`:** sizes the box: `size-10 rounded-full` for an avatar,
  `h-4 w-64` for a line of text. The pulse is a layer inside the box, so your
  classes size it and the animation is unaffected.
- Say that something is loading somewhere a reader does hear, such as a
  `busy` state on the region or an `Alert` when it is done. The skeleton
  says nothing.
