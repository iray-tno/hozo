`FileDropzone` takes files dropped onto it, and is also a button that opens the
file picker. Drop an image on it, or press it:

<UiExample source={source} file="FileDropzoneDemo.tsx">
  <FileDropzoneDemo client:visible />
</UiExample>

- **A button first.** Dragging has no keyboard or screen-reader equivalent, so
  the zone is a real `<button>`, and Enter and Space open the picker. The drop
  is a shortcut on top of it.
- **`accept`**, **`maxSize`**, **`minSize`**, **`multiple`** and **`maxFiles`**
  are the rules. Files that break one go to **`onRejected`** with a reason,
  and the rest go to **`onFilesSelected`**.
- **What was added and what was refused is announced** in one sentence, such as
  "a.gif is not an accepted kind of file", so a refusal is not only a red line
  a reader cannot see.
- **`accessibilityLabel`** names the button. **`children`** are what it shows.
- **On Native**, the zone opens your `pickFiles` adapter or an installed
  `expo-document-picker`. Its `className` styles the button; literal labels
  receive its text styles, while custom child components retain their own.
  **`activeClassName` is Web drag-over styling**: it is not applied while a
  Native button is pressed or its picker is busy. Native file-drag events
  remain a separate capability, and the status above continues to list that
  prop as unapplied.
