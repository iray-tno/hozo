`Tree` shows nested items that open and close. Click a folder, or Tab into the
tree and use the arrow keys:

<UiExample source={source} file="TreeDemo.tsx">
  <TreeDemo client:visible />
</UiExample>

- **`nodes`:** `{ id, label, children? }`. A node with `children` is a branch
  that can expand.
- **`defaultExpanded`** lists the ids that start open.
- **`selectedId`** and **`onSelect`** hold the selected item.
- **A click on a branch selects it and opens or closes it**, because the marker
  is a chevron, which reads as "this row opens". When branches are things to
  choose rather than folders, or the marker is a `+` box, `@hozo/patterns`'
  `Tree` takes `toggleOn="marker"`: then only the marker opens and closes.
- **The keyboard follows the ARIA tree pattern:**
  - Up and Down move between visible rows.
  - Right opens a branch, or moves into it once it is open.
  - Left closes a branch, or moves to its parent.
  - Enter selects.
  - Typing a letter moves to the next row that starts with it.
  - In a right-to-left interface, Left and Right swap.
- **The open and closed marker is drawn by CSS**, not written into the label.
  A reader already hears "expanded" or "collapsed", so a ▾ in the text would
  say it twice.
- **`renderRow`** replaces what a row shows. It is given the row's level and
  whether it is open.
