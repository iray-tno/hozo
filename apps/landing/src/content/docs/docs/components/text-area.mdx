A `TextArea` grows as it is typed into, between `minRows` and `maxRows`, and
scrolls after that. With `maxLength`, it shows how many characters are left.
The count is a description rather than a live region: a screen reader reads it
on reaching the field, and announces it unprompted only twice, entering the last
ten characters and running out.

- **`value`** and **`onChangeText`**, or **`defaultValue`**.
- **`minRows`** and **`maxRows`:** line counts rather than pixels, so they
  survive a change of text size.
- **`maxLength`:** the limit and the counter.
- Inside a [`Field`](../input/), `{...control}` passes the label, the
  description and the error, as it does for `Input`.
